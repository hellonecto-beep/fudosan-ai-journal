# 物件紹介文を5分で書くAIプロンプト集（5パターン）

物件紹介文を書く作業は、不動産営業の中でも特に「地味だけど時間が消える」業務の代表格です。1物件あたり30分から1時間かかることも珍しくなく、月に何十件と書く方にとっては大きな負担になっています。本記事では、ChatGPT や Claude などの対話型AIに渡せば、物件紹介文を5分で1本書き上げてくれるプロンプト（AIへの指示文）を5パターン、コピー&ペースト用で公開します。賃貸・売買・店舗・新築・リフォーム済み、それぞれの用途に最適化したものです。

## プロンプトを使う前の準備

どのプロンプトも、最初に物件の基本情報をAIに渡す必要があります。所在地、間取り、平米数、築年数、最寄り駅と徒歩分数、家賃または価格、設備、特徴、ターゲット層、この9項目をメモ帳に書き出しておくとスムーズです。物件マイソクや既存の登録情報からコピーすれば1〜2分で揃います。

なお、AIに渡す情報に**個人情報（オーナー名や入居者名）は絶対に含めないでください**。万一AIサービス側で履歴が保存された場合、情報漏えいに繋がります。社内ポリシーで定めておくことをお勧めします。

## パターン1：賃貸物件向け（一般ファミリー向け）

```
あなたは不動産の賃貸物件紹介文の専門ライターです。
以下の物件情報から、ファミリー層に響く紹介文を400字程度で作成してください。

【物件情報】
所在地: 東京都〇〇区〇〇 1-2-3
間取り: 3LDK
平米数: 72㎡
築年数: 築8年
最寄り駅: 〇〇駅 徒歩7分
家賃: 14万円
設備: 食洗機、浴室乾燥機、宅配ボックス、ペット可
特徴: 角部屋、南向き、目の前に公園あり

【執筆ルール】
- 冒頭で家族の生活シーンが目に浮かぶ書き出し
- 設備は単に列挙せず、暮らしのメリットに翻訳
- 「最高」「絶対」など誇大表現は使わない
- 280〜400字以内
```

ポイント：「設備の列挙ではなく暮らしのメリットに翻訳」と指示することで、AIが「食洗機 → 共働き家庭の家事時短に」のような変換をしてくれます。

## パターン2：売買物件向け（投資・実需両用）

```
あなたは不動産の売買物件紹介文の専門ライターです。
以下の物件について、購入検討者が「次の内覧予約をしたくなる」紹介文を500字で作成してください。

【物件情報】
所在地: 神奈川県〇〇市〇〇 2-4-5
種別: 中古マンション
間取り: 2LDK + S(納戸)
専有面積: 65㎡
築年数: 築15年（外壁修繕済み2024年）
階数: 12階建ての8階
販売価格: 4,280万円
特徴: 駅近、リフォーム済み、管理状況良好

【執筆ルール】
- 投資目線（利回り、賃貸需要）と実需目線（住み心地）の両方に触れる
- 築15年というネガティブ情報は、修繕履歴で安心感に変換
- 「お買い得」「絶対」などの煽り表現はNG
- 数字の根拠を必ず本文に盛り込む
```

ポイント：築年数のような「マイナスに見える情報」をどう扱うかを明示すると、AIが上手にポジティブな文脈に再構成してくれます。

## パターン3：店舗・事務所向け（事業者ターゲット）

```
あなたは不動産の事業用物件紹介文の専門ライターです。
以下の店舗物件について、飲食店オーナーを想定読者に紹介文を400字で作成してください。

【物件情報】
所在地: 大阪府〇〇市〇〇 1-1-1
物件種別: 1階路面店舗
面積: 35㎡（前店舗：カフェ）
最寄り駅: 〇〇駅 徒歩3分
賃料: 月28万円（共益費別）
特徴: ガス容量大、グリストラップ既設、看板設置可

【執筆ルール】
- 業種別の使いやすさ（特に飲食）を具体的に
- 周辺の人通り・客層など立地メリットを推測で書かない、事実のみ
- 居抜きの設備を活かせる業種をいくつか提案
- 開業コストを抑えられる点を強調
```

ポイント：「推測で書かない、事実のみ」と明示することで、AIが「人通りが多い」のような確認できない記述を控えるようになります。

## パターン4：新築・新規物件向け（先進性訴求）

```
あなたは不動産の新築物件紹介文の専門ライターです。
以下の新築マンション情報から、20〜30代の購入検討者に響く紹介文を500字で作成してください。

【物件情報】
所在地: 福岡県〇〇市〇〇 3-5-7
種別: 新築分譲マンション
間取り: 1LDK
平米数: 42㎡
販売価格: 3,180万円〜
完成予定: 2027年3月
特徴: 駅徒歩2分、共用ジム、宅配ボックス、太陽光発電、IoT連携

【執筆ルール】
- 新築ならではの最新設備・省エネ性能をしっかり訴求
- 「初期不良がない」など新築のメリットを具体的に
- 完成前物件であることを正直に書きつつ、入居までの時間軸を明示
- ライフスタイル（在宅勤務、共働き）と紐付けて魅力を伝える
```

ポイント：未完成物件は誤解を生みやすいので、「正直に書きつつ」を入れて誇大表現を抑制します。

## パターン5：リフォーム済み中古向け（バリュー訴求）

```
あなたは不動産のリフォーム済み中古物件紹介文の専門ライターです。
以下の物件について、新築は手が届かないが快適な暮らしを求める読者に向けて、紹介文を400字で作成してください。

【物件情報】
所在地: 愛知県〇〇市〇〇 4-6-8
種別: 中古戸建（リフォーム済み）
間取り: 3LDK+S
土地面積: 100㎡
建物面積: 95㎡
築年数: 築22年
販売価格: 2,680万円
リフォーム内容: 水回り全面、壁紙、フローリング、外壁塗装（2025年完了）

【執筆ルール】
- 「新築と中古の中間」のお得感を強調
- 具体的なリフォーム内容を読者の生活シーンに変換
- 築年数のマイナスを補修履歴でカバー
- 「お買い得」「絶対」は使わない
```

ポイント：リフォーム済み物件はバリュー（コスパ）訴求が刺さりやすいので、「新築と中古の中間」というポジショニングを明示します。

## 5つのプロンプト共通の使い方のコツ

これら5つのプロンプトを使う時の共通テクニックを4つ紹介します。

1つ目は、最初に1度AIに書かせてから、気になる箇所を「ここをもう少し〇〇に」と追加指示することです。AIは一発で完璧を狙うより、対話で磨く方が良い結果になります。

2つ目は、自社のブランドトーンに合わせる時に「私たちの会社のキャッチフレーズは『暮らしを変える、住まいを選ぶ』です。このトーンに寄せてください」と冒頭に入れることです。社風が文章に乗ります。

3つ目は、長すぎたら「200字に縮めて」と指示することです。AIは縮めるのは得意なので、最初は長めに書かせて圧縮するのが効率的です。

4つ目は、出力結果を必ず人間が最終チェックすることです。事実誤認や法的に問題のある表現が混ざる可能性はゼロではありません。**不動産表示規約に詳しい担当者の目を必ず通す**運用にしてください。

## まとめ

物件紹介文の作成は、適切なプロンプトを使えばAIで5分以内に下書きが完成する作業になります。1日に何十件と扱う不動産会社にとって、月に数十時間の業務時間削減が現実的に見込めます。今回紹介した5パターンは、コピー&ペーストでそのまま使えるよう設計してあるので、まずは1物件で試してみてください。私たち Necto では、こうした業務効率化の導入支援を不動産会社向けに行っていますので、「自社の業務に合わせたプロンプトを作りたい」というご相談もお気軽にどうぞ。
